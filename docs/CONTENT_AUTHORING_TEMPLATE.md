## Learning design

### Learning objectives
Write measurable outcomes beginning with verbs such as identify, explain, compare, calculate, interpret, or justify.

### Prior knowledge
List only the knowledge the learner needs before starting.

### Key vocabulary and notation
For each term, give an original learner-friendly Arabic explanation. Include symbols, units and English equivalents only when useful.

### Core explanation
Write in short sections. Explain the idea, show why it works, then connect it to the curriculum. Cite claims that rely on an external scientific or reference source.

### Visuals / diagrams
For each visual, record whether it is original, licensed, public domain or link-only. Include creator, exact source, licence and attribution. Do not paste textbook or website diagrams without permission.

## Original question bank

Create a balanced mix when suitable to the subject and grade:

- Recall / understanding
- Application
- Multi-step reasoning or problem solving
- Interpretation of data, diagrams, sources or text

For each question record:
- Learning objective
- Difficulty: easy / medium / advanced
- Question type
- Original prompt and original options/data
- Correct answer (stored privately)
- Step-by-step explanation
- Marking criteria for open responses
- Source references used to validate the underlying concept (not necessarily a source that supplied the question)
