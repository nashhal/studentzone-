# Primary foundation lesson batch — Yemen Study

Reviewed: 24 November 2026

## Purpose and boundaries

This is the first original lesson-authoring batch connected to the student-facing website. It is based on the Ministry planning document **الصفوف الاولية ( 1 - 3 ) 2026 -2027.pdf** and its page-level topic plans. It covers selected foundational topics only. It is not a complete lesson map for Grades 1–3 and is not a substitute for the school's approved textbooks.

## Visual authoring rule

Illustrations in this batch are original vector diagrams. Future topics should use an appropriate original diagram, labelled process, map or data visual when it improves understanding. A visual must support the learning objective; it should not be added merely as decoration. External images require an explicit rights check and attribution record before publication.
