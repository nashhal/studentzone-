# Yemen Study

منصة تعليمية عربية للمناهج اليمنية، تبدأ بالصف الثالث الثانوي – المسار العلمي، ثم تتوسع لبقية الصفوف.

## مبادئ المشروع
- واجهة عربية RTL، متجاوبة، ومصممة للهاتف أولاً.
- محتوى أصلي أو مرخّص فقط؛ لا يعاد نشر الكتب أو الاختبارات المحمية دون إذن.
- حسابات طلاب ومحررين ومديرين بصلاحيات منفصلة.
- قاعدة بيانات PostgreSQL عبر Supabase مع سياسات Row Level Security.
- لا توضع مفاتيح Supabase السرية أو مفاتيح service-role في تطبيق المتصفح.

## التطوير
يتم تنفيذ العمل على فرع تطوير مستقل، وتبقى `main` فرع الإصدار المستقر. راجع ملف `docs/ROADMAP.md` بعد بدء فرع التطوير لمعرفة نطاق الإصدار الأول.
